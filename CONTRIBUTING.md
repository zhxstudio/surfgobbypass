# Участие в разработке

Опишите проблему в issue, приложите шаги воспроизведения и диагностику без личных данных.

Для изменений используйте отдельную ветку. В pull request опишите результат и выполненные проверки. Соберите проект командой `./gradlew.bat --no-daemon assembleRelease lintRelease` на Windows с JDK 17 и SDK 35. Изменения Root/Shizuku проверяйте на устройстве, указывая способ доступа и версию Android.

Не добавляйте ключи подписи, пароли, local.properties, APK и результаты сборки в исходники. APK публикуются вложениями GitHub Releases.
